# Visnob
Your vision for the next job hunt : AI-driven personalized skill upgradation and career path planning

AI-driven personalized skill analysis and career path planning project.

## Overview

Visnob analyzes student academic performance, technical skills, projects, experience, and certifications to identify suitable career opportunities and provide a possible skill-upgradation path.

The project uses student data and job/company data to explore clustering, skill matching, and career recommendations.

## Current Components

- `career_matcher.py` — Main career matching and clustering program
- `student_data.csv` — Student dataset
- `brands_data.csv` — Company/job dataset

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- K-Means Clustering
